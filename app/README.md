# Система управления конференцией

Веб-приложение для управления участниками конференции, оргвзносами и отчетностью.

## Технологии

- **Backend**: Python 3, Flask, SQLAlchemy, SQLite
- **Frontend**: HTML, CSS, JavaScript

## Установка

1. Убедитесь, что у вас установлен Python 3.7 или выше:
```bash
python --version
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

Запустите приложение:
```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Структура проекта

```
app/
├── app.py              # Основной Flask приложение с API
├── models.py           # Модели базы данных
├── requirements.txt    # Зависимости Python
├── index.html          # Фронтенд приложения
├── styles.css          # Стили
└── conference.db       # База данных SQLite (создается автоматически)
```

## API Endpoints

- `GET /api/participants` - Получить всех участников
- `POST /api/participants` - Создать нового участника
- `GET /api/participants/<id>` - Получить участника по ID
- `POST /api/invitations/search` - Поиск приглашенных по дате
- `GET /api/fees` - Получить всех участников с оргвзносами
- `POST /api/fees/search` - Поиск оргвзносов по периоду
- `POST /api/reports/thesis` - Отчет по тезисам
- `POST /api/reports/hotel` - Отчет по запросам на гостиницу
- `GET /api/cities` - Получить список городов

## Функциональность

- Добавление и просмотр участников конференции
- Поиск приглашенных по дате рассылки
- Управление оргвзносами
- Генерация отчетов:
  - Тезисы докладов по городам
  - Запросы на проживание по городам

## База данных

При первом запуске автоматически создается база данных SQLite с тестовыми данными (2 участника).
